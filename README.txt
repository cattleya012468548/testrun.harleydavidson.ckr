IRON & EMBER — MOTORCYCLE DEALER WEBSITE
========================================

Contents
- index.html
- css/style.css
- js/script.js

How to preview
1. Extract the ZIP file.
2. Open index.html in a modern browser.
3. Internet access is needed for Google Fonts and the remote motorcycle photographs.

Design palette (from the supplied reference)
- Black: #000000
- Red: #CF0A0A
- Orange: #DC5F00
- Light grey: #EEEEEE

Features
- Responsive landing page with mobile navigation
- Motorcycle category filters
- Model cards linking to official Harley-Davidson model pages
- Dealer enquiry form demo with front-end validation/message
- Responsive layouts and reduced-motion support

Image note
The motorcycle images are loaded from Unsplash URLs and are illustrative. They may not all depict specific Harley-Davidson models. For a production dealer site, replace these with dealership-owned or properly licensed photographs of the exact models. The official Harley-Davidson lineup link is included.

Brand note
“Iron & Ember Motorcycle Co.” is a fictional concept dealer name. This concept is not affiliated with or endorsed by Harley-Davidson Motor Company.
